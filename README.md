# dMAT Study Kit — Summer Semester 2027

Aptitude prep for the **Digital Master Assessment Test** (APS India path: **Core Module + General Academic Module**).

**Exam date:** 26 September 2026  
**Study load:** ~3 hours/day, 6 days/week (cap ~5 hrs on mock days)  
**Rule:** practice **without notes** — the exam forbids them.

**To run the prep app:** install Python 3 — see [PREREQUISITES.md](PREREQUISITES.md).

## Daily block (~3 hrs)

1. **Warm-up (20–30 min)** — one subtest type  
2. **Drill (60–90 min)** — 1–2 difficulty tiers, no notes, then check solutions  
3. **Review (30–45 min)** — one mistake-log line per miss  
4. **Optional** — one short GAM scenario or UI video
