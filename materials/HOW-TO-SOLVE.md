# How to solve (solution workflow)

Use this order every time. Official PDF items have printed solution paths — use those after you attempt. App items show **Answer + explanation** after **Check** or **Reveal solution**.

**Do not copy answers from memory into the real exam.** Practice the *process*.

---

## Shared rules (all types)

1. Read the short instruction reminder.
2. Attempt without notes (exam forbids them).
3. If stuck near the end of the clock → eliminate → **guess** (blank is worse if guessing is free).
4. After practice: log one line in [mistake-log.md](../mistake-log.md); review [CHEATS.md](CHEATS.md).

Official authentic solutions live only in g.a.s.t. PDFs ([SOURCES.md](SOURCES.md)). This repo does not republish them.

---

## Figure Sequences

**Goal:** Pick the matrix that continues the series.

1. List figures in frame 1 (count them).
2. For each figure, track **MOVE → SPIN → HUE → STEP** across frames 1–4.
3. Apply the same rule(s) to get frame 5.
4. Match that frame to an option; reject options that break **NO-GHOST** or edge rules.

**Common miss:** Ignoring x+1 step growth or bounce-at-edge.

---

## Mathematical Equations

**Goal:** Find the value of the asked letter.

1. **PIN** the simplest equation (often `Letter = number`).
2. **CHAIN** substitutions until the target is known.
3. Confirm all letters are **distinct** and in **1–20**.
4. If two options remain, plug both into every equation.

**Common miss:** Forgetting uniqueness or arithmetic on a multi-letter sum.

---

## Latin Squares

**Goal:** Letter for `?` (A–E, once per row and column).

1. Find the **fattest** row or column touching `?`.
2. **CROSS OUT** letters already used in that row and column.
3. If still ambiguous, resolve a nearby empty cell, then return to `?`.

**Common miss:** Starting on a nearly empty row (too many possibilities).

---

## General Academic Module

**Goal:** Answer questions from a short academic scenario.

1. Skim once for structure (what is measured / constrained).
2. Mark **GIVENs** (numbers, limits, definitions).
3. For each question: compute or infer only from givens.
4. **KILL CONTRADICTIONS** among options; pick the survivor.
5. Watch units and “at least / at most / must not.”

**Common miss:** Treating a plausible inference as a given.
