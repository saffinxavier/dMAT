# Week 6 (19–26 Sep) — Taper + exam day

**Goal:** Stay sharp, stay rested, sit the exam calmly.  
**Load:** 60–90 min/day until 24 Sep; no heavy new material after that.  
**Exam:** **26 September 2026**

**Materials:** [Mistake log](../mistake-log.md) · [Registration](../registration-checklist.md) · [APS checklist](../aps-checklist.md) (open after results)

## Day-by-day

### Day 1 (19 Sep) — Weak Core only
- [ ] 60–90 min on single weakest Core type
- [ ] Skim starred mistakes in the log

### Day 2 (20 Sep) — Light GAM
- [ ] 60–90 min: quick GAM question set / revisit one scenario
- [ ] No new strategies

### Day 3 (21 Sep) — Half mock (light)
- [ ] One Core subtest **25 min** + short GAM block (~30–40 min)
- [ ] Brief review only

### Day 4 (22 Sep) — Mixed short drills
- [ ] Rotate FS / ME / LS in short bursts (10–15 min each)
- [ ] Stop if accuracy drops from fatigue

### Day 5 (23 Sep) — Confidence pass
- [ ] Re-do 3–5 items you now get right every time (confidence, not grind)
- [ ] Pack exam bag checklist below

### Day 6 (24 Sep) — Stop heavy study
- [ ] Optional 30–45 min light review of cheatsheet only
- [ ] Sleep priority; no full mocks

### 25 Sep — Rest day
- [ ] No drills (or ≤20 min calm rule skim)
- [ ] Confirm travel time to centre; charge devices for morning alarm only
- [ ] Early night

### 26 Sep — Exam day
- [ ] ID + registration confirmation
- [ ] Arrive early
- [ ] Core: watch the clock per 25-min subtest; guess blanks
- [ ] Use the break; reset for GAM
- [ ] GAM: given data first, eliminate contradictions, guess remaining

## Exam bag

- [ ] Valid ID (same as registration)
- [ ] Registration confirmation (print or offline copy)
- [ ] Centre address + route
- [ ] Water / snack for before/after (follow centre rules inside)
- [ ] Nothing for notes (not allowed)

## After the exam

- [ ] Do not spiral on score — dMAT is not pass/fail for APS
- [ ] Certificate target date: **12 Oct 2026**
- [ ] Open [aps-checklist.md](../aps-checklist.md) and prepare to upload the certificate

## Checkpoint

- [ ] Taper followed (no cramming after 24 Sep)
- [ ] Logistics ready
- [ ] Exam sat on 26 Sep
