# Week 5 (12–18 Sep) — Full mocks

**Goal:** Core mock, GAM mock, then one full exam simulation.  
**Load:** Up to ~5 hrs on mock days; otherwise ~3 hrs.  
**Note:** Registration deadline **15 Sep** — you should already be registered.

**Materials:** [Prep PDF](https://www.d-mat.de/wp-content/uploads/2026/07/260716_dMAT_General-Academic-Module_Preparatoy-Materials_EN.pdf) · [Mistake log](../mistake-log.md)

## Mock rules (all)

- Computer or printouts OK; **no notes**, no calculator, no phone
- Single-choice only; guess blanks before time ends
- Use a real timer; take the scheduled break on Mock C
- After each mock: 30 min review → mistake log only for repeat errors

## Day-by-day

### Day 1 — Mock A: Core only
- [ ] FS 25 min + ME 25 min + LS 25 min (or continuous ~75 min)
- [ ] 30 min review + log
- [ ] Note which subtest was slowest: _______________

### Day 2 — Light recovery
- [ ] 60–90 min: only items from Mock A misses
- [ ] Optional: short academic English reading (inference practice)

### Day 3 — Mock B: GAM only
- [ ] **90 min** on GAM-style work (Exercises 1–3 under exam conditions / time-boxed)
- [ ] 30 min review + log
- [ ] Note: ran out of time? Y/N ______

### Day 4 — Light recovery
- [ ] Fix top 3 GAM mistake patterns from Mock B
- [ ] 1 short Core warm-up (20 min), weakest type only

### Day 5 — Mock C: Full simulation
- [ ] Core (~75 min) → **30 min break** → GAM (90 min)
- [ ] Full review after; update weak-spot tracker
- [ ] Logistics re-check: confirmation + ID + travel

### Day 6 — Debrief
- [ ] Re-read mistake log; star the 5 errors most likely on exam day
- [ ] Plan Week 6 taper focus (one Core type + light GAM)
- [ ] Week 5 checkpoint

## Checkpoint

- [ ] Mock A (Core) done
- [ ] Mock B (GAM) done
- [ ] Mock C (full ~3.5 h) done
- [ ] Still registered; ignore last-minute registration panic
