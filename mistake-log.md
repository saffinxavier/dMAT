# Mistake Log

One line per miss. No essays. Review this before every timed drill.

**Rules:** Practice **without notes** (exam forbids them). After checking solutions, write only what you will spot next time.

**Memory codes (source of truth):** [materials/CHEATS.md](materials/CHEATS.md) · **Solve order:** [materials/HOW-TO-SOLVE.md](materials/HOW-TO-SOLVE.md) · **Weekly tracker:** [progress/TRACKER.md](progress/TRACKER.md)

## How to use

| Column | What to write |
| --- | --- |
| Date | Study day |
| Type | FS / ME / LS / GAM |
| Item | Exercise # or “mock” |
| Miss | What went wrong in ≤1 sentence |
| Fix | Cheat code or habit (e.g. PIN→CHAIN, FAT FIRST) |

**Abbreviations:** FS = Figure Sequences · ME = Mathematical Equations · LS = Latin Squares · GAM = General Academic Module
