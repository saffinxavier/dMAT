# dMAT Registration Checklist

**Target exam:** 26 September 2026  
**Registration deadline:** 15 September 2026 (seats first-come — do this in Week 1)  
**Fee:** €150 (paid to g.a.s.t. at registration)  
**Module:** Core + General Academic Module (APS India)

## Before you start

- [ ] Confirm you need dMAT: bachelor’s in Engineering / Commerce–Accounting–Finance–Economics / Business–Management, applying for Summer Semester 2027 or later
- [ ] Check exemptions on [aps-india.de/dmat](https://aps-india.de/dmat/) (APS started before 29 Jun 2026, partnership programmes, etc.)
- [ ] Have a valid ID ready (passport preferred for test-day match)
- [ ] Decide preferred test city (and 1–2 backups)

### Test centres (planned)

Ahmedabad, Bengaluru, Bhopal, Chandigarh, Chennai, Kolkata, Mananthavady, Mumbai, New Delhi, Pune, Kathmandu (Nepal). Final list appears during registration.

## Register

1. [ ] Open the [g.a.s.t. dMAT exam portal](https://www.gast.de/portal/center-search/center-search/dmat/exams/worldwide?lang=en)
2. [ ] Create / log into your g.a.s.t. account
3. [ ] Select **dMAT**, date **26 September 2026**, **General Academic Module**
4. [ ] Pick a test centre and confirm seat
5. [ ] Pay €150 and save payment confirmation
6. [ ] Download / screenshot registration confirmation (exam time, centre address, candidate ID)
7. [ ] Add exam day to calendar + travel buffer
8. [ ] Store confirmation PDF in a safe folder (and optionally note the path below)
